# Nenolink Text Tools v0.4 — krav

v0.4 udvider v0.3 til en lokal, deterministisk og multilingual QA-platform uden cloud-upload, telemetry eller automatisk ændring af originaler.

Initiale UI-/data-sprog: `da`, `sv`, `nb`, `en`, `de`, `fr`. UI-sprog, source-sprog og target-sprog er uafhængige. Regelcoverage dokumenteres pr. rule pack; seks valgbare sprog betyder ikke fuld coverage af alle 30 retninger.

Eksisterende Text Marker, Translation Risk Scanner, DA-interferensscan, Word Index, File Inventory og gamle CSV-formater skal bevares. Bilingual semantic comparison, TBX, cloud AI, betaling og licensing er uden for MVP.
