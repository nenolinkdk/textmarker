# Nenolink Text Tools v0.3 — krav

v0.3 tilføjer en uafhængig regelbaseret DA-interferensscanner til den eksisterende launcher. Den analyserer danske DOCX-oversættelser lokalt og ændrer aldrig originalen.

## MVP

- Femte modul: DA-interferensscan.
- Dansk DOCX + valideret, redigerbar CSV-regelfil.
- RED, ORANGE og YELLOW som review-indikatorer, ikke bekræftede fejl.
- Markerede DOCX-kopi, forekomst-CSV og valgfri summary-CSV.
- Kategorifiltrering, progress, cancellation, sikker output-publicering og File Inventory-registrering.
- Eksisterende fire moduler og deres CSV-formater forbliver uændrede.

## Ikke i v0.3

Semantisk ækvivalens, automatisk oversættelse, omskrivning og norsk/dansk alignment er kun arkitekturforberedelse.
