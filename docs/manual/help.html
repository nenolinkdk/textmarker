Risk rules and CSV

Translation Risk Scanner requires the exact columns expression (literal text to search), category (your review grouping), color (Word highlight palette), severity (low, medium or high), explanation (why the expression merits review), suggestion (what to check) and enabled (true/false). UTF-8/BOM and comma or semicolon delimiters are supported; rule IDs are generated in file order. A row is a possible review risk, not a confirmed translation error.

Language Interference rules and CSV

Language Interference Scanner requires the exact columns rule_id, expression, language, category, severity, color, explanation, suggestion and enabled. UTF-8/BOM and comma or semicolon delimiters are supported. Valid languages are da, nb, no and mixed; categories are RED, ORANGE and YELLOW. The bundled compatible example is data/examples/da_interference_rules.csv.

Promptbibliotek

Åbn Promptbibliotek fra navigationen for at se lokale skabeloner og gemte prompts. Vælg en prompt, redigér teksten, og brug Gem tilpasset prompt, Duplikér eller Eksportér tekst. Promptdata gemmes lokalt; ingen tekst sendes til en ekstern tjeneste.

Prompt Builder-arbejdsgang

Vælg en opgave, sprog, domæne, kvalitetskriterier og resultatstruktur, og tryk Næste gennem FSM-flowet. I forhåndsvisningen kan prompten redigeres før Gem. Brug Tilbage og Nulstil til at ændre flowet. En prompt er en redigerbar reviewinstruktion, ikke et automatisk svar.

Fejlfinding

Hvis en manual ikke åbnes, kontrollér at den pakkede EXE indeholder docs/manual/help.html. Hvis Promptbiblioteket er tomt, gem først en prompt fra Prompt Builder. Hvis en scanner afviser en CSV, kontrollér schemaets nøjagtige kolonnenavne og UTF-8-kodning.

Dashboard — dansk procedure

Dashboard er startpunktet for et lokalt review. Tryk Åbn modul for at åbne den valgte funktion, eller brug projektindstillingerne til at vælge projektmappe, kildesprog og målsprog. Dashboard behandler ikke dokumentet selv og ændrer ikke manuskriptet.

Forventet resultat: Du ender på den relevante modulside med adgang til filvælgere, regler og output. Hvis et sprogpar ikke har en kompatibel regelpakke, skal du vælge regler eksplicit i det relevante modul.

Project Workflow — dansk procedure

Udfyld Projektnavn og Projektmappe, vælg Kildesprog og Målsprog, og tryk Gem projekt. Brug derefter Importér rule pack og Aktivér valgte packs. Vælg DOCX-filen, tryk Start scanning, og følg status- og progressvisningen.

Fejl: Manglende filer, inkompatible sprogpar eller eksisterende output afvises. Et vellykket workflow viser markeret DOCX og CSV-rapporter og registrerer relevante filer i File Inventory.

Promptbibliotek — dansk procedure

Åbn Promptbibliotek. Listen starter med seks linjer mærket Indbygget. Vælg Terminologikontrol, vælg Kildesprog Norsk bokmål og Målsprog Dansk, og skriv fx Litterær oversættelse i Domæne/genre. Tilpas Kvalitetskriterier og Resultatstruktur. Den fulde prompt vises i editoren og kan redigeres.

Tryk Kopiér prompt for udklipsholderen eller Duplikér for at gemme en personlig version. Gem tilpasset prompt skriver en ny lokal prompt; indbyggede skabeloner ændres aldrig. Eksportér tekst gemmer en personlig prompt som TXT. Prompten udfører ingen AI-analyse og uploader ikke manuskript.

Prompt Builder — dansk procedure

Vælg Opgave, Kildesprog, Målsprog, Domæne, Kvalitetskriterier og Resultatstruktur. Tryk Næste gennem FSM-trinene; Tilbage går ét trin tilbage, og Nulstil rydder forløbet. I forhåndsvisningen kan teksten ændres før Gem. Brug Åbn gemt prompt til at genåbne en lokal prompt.

Et godt resultat indeholder tekstbelæg, usikkerhed og en klar skelnen mellem observation, mulig problemstilling og bekræftet fejl. Brug først prompten i et eksternt værktøj, når du selv har fjernet fortroligt materiale, hvis det er nødvendigt.

Rule-file schemas and examples

Keep the three formats separate. Translation Risk uses expression, category, color, severity, explanation, suggestion and enabled; the loader assigns rule IDs. DA-interference additionally requires unique rule_id and language, and validates RED/ORANGE/YELLOW categories and da/nb/no/mixed languages; use data/examples/da_interference_rules.csv. Canonical v0.4 packs use rule_pack_id, rule_pack_version, rule_id, source_language, target_language, expression, category, severity, explanation, suggested_review and enabled. Preserve exact headers and validate each file in its matching module.

Creating and editing a rule file

Copy the bundled example when available, retain its exact header and save as UTF-8 CSV. Fill explanation and suggestion so a reviewer understands why a match deserves attention. Select the file in the matching scanner, resolve validation messages before scanning, then compare every marked occurrence with its surrounding source and target context.

Running a scan

Select the source document and rule CSV, run the scanner, then compare marked Word text with the source and target context. A finding is a possible risk or interference, not proof of a confirmed translation error.

Translation Risk Scanner tutorial

Use a Norwegian DOCX or a synthetic Norwegian paragraph, copy data/examples/risk_rules_no_da.csv to a writable folder with the example action, select it as Risk rules, choose an output DOCX and start scanning. Open the marked output and compare each highlighted occurrence with the Danish translation; false friends and similar-looking Nordic forms are candidates for review, not automatic corrections.

Interpreting findings

False friends and related-language interference can resemble correct cognates. Verify every highlighted occurrence against context and revise only when the evidence supports it.

Word Index and interference

Use frequency and stopword-filtered output to identify repeated terms and possible interference candidates; the index does not determine translation errors.

Building terminology resources

Create concepts, add terms with language and status, import mapped customer CSV rows, review possible duplicates and export canonical terminology.

First-run tutorial

The local tutorial uses bundled sample files and writes only to a user-selected or temporary local output directory. It does not upload manuscript or terminology content. Tutorial steps are a guided introduction; the full module procedures above describe validation and limitations.
